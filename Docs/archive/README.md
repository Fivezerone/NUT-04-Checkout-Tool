# Historical Documentation Archive & Deprecation Ledger

## Purpose & Scope
This directory serves as the permanent historical archive for all exploratory blueprints, legacy requirements documents, refactor ledgers, academic research decks, and superseded specifications created during the evolution of the **NUT-04 Checkout Tool** (v0.1 through v1.1.0).

> [!IMPORTANT]
> **Do Not Delete Archive Materials:** Historical notes, student presentations, and deletion ledgers are preserved here as an evidentiary audit trail. If you are developing new features or refactoring the system today, **do not rely on archived documents as the source of truth**. Consult the living tiers in [docs/architecture/](../architecture/) and [docs/operations/](../operations/).
